# NetCheck 🔍

Um script leve em Python para monitoramento automatizado de conectividade de rede (Ping) e verificação de portas TCP abertas, projetado para ambientes Linux.

## 🚀 Como Executar

1. Certifique-se de ter o Python 3 instalado no seu Debian.
2. Clone o repositório ou baixe os arquivos na mesma pasta.
3. Edite o arquivo `config.json` para adicionar os IPs ou domínios que deseja monitorar.
4. Execute o script via terminal:

```bash
python3 main.py
